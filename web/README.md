# NEXORA mobile web prototype

This folder is a zero-dependency browser prototype intended for fast gameplay/UI testing on iPhone and Android browsers while the main Unity project is developed.

Current loop: PLAY → move astronaut with touch joystick → SCAN/GATHER resources → BUILD → place Earth Outpost.

To test it from a phone it must be hosted over HTTPS (for example via a static hosting deployment). This source existing in GitHub alone does not create a public playable URL.
